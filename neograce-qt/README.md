# NeoGrace

*English: a modern editor for Grace (.agr) plots — a native Apple Silicon replacement for
xmgrace/QtGrace. The interface is available in English and Russian (View → Язык / Language).*

Современный редактор графиков в формате **Grace (.agr)** — замена xmgrace/QtGrace,
которая нативно работает на Mac с Apple Silicon (arm64) и не зависит от Rosetta.
Написан на C++17 и Qt 6.

![](packaging/NeoGrace.png)

## Что умеет

**Файлы**
- Открывает и сохраняет `.agr` (и старые `.par`/`.xmgr`). Команды, которых NeoGrace не
  знает (регионы, `stack world`, `timestamp`, `link`…), сохраняются как есть, так что
  файл после NeoGrace открывается в xmgrace без потерь.
- Читает `.xvg` (GROMACS) и текстовые таблицы (`.dat`, `.txt`, `.csv`, `.tsv`): пробелы,
  табуляции, запятые, `;`, блоки через `&`, заголовки столбцов.
- Экспорт: PDF и SVG (вектор, шрифты остаются текстом), PNG, JPEG, TIFF с любым dpi и
  прозрачным фоном; печать; «Копировать как картинку» для вставки в Keynote/Word.
- Пакетный режим без окна (как `gracebat`):
  `NeoGrace --export рисунок.pdf проект.agr` (`--dpi 600`, `--transparent`).

**Отрисовка** — масштабы взяты из исходников Grace (шрифт, символы, засечки, линии,
легенда, раскладка подписей), поэтому проекты выглядят так же, как в xmgrace, но со
сглаживанием, современными шрифтами и знаком «−» вместо дефиса.
- Графики XY, Chart (бары рядом и в накоплении), Polar, Pie, Fixed; несколько графиков
  на странице, вставки.
- Все типы наборов: xy, xydx, xydy, xydxdx, xydydy, xydxdy, xydxdxdydy, bar, bardy,
  bardydy, xyhilo, xyz, xyr, xysize, xycolor, xycolpat, xyvmap, xyboxplot, xystring.
- Символы, 8 стилей линий, ступеньки, заливки до базы и многоугольником, узоры,
  погрешности (в т.ч. обрезанные стрелкой), выносные линии, подписи значений.
- Шкалы: линейная, логарифмическая, обратная 1/x, логит; обращение осей; верхняя и
  правая оси; оси через ноль; особые деления со своими подписями; форматы подписей
  (общий, десятичный, степень 10ⁿ, научный, инженерный k/M/µ, компьютерный K/M, даты,
  градусы); формула пересчёта подписей (`$t - 273.15`).
- Разметка текста Grace: `\S \s \N`, `\x` (греческие буквы), `\f{…}`, `\+ \-`,
  `\u \o`, `\R{цвет}`, `\#{код}`. Греческие буквы можно набирать с клавиатуры.
- Надписи, линии со стрелками, прямоугольники, эллипсы — в координатах страницы или
  графика.

**Правка**
- Холст: выделение щелчком, перетаскивание легенды, надписей и фигур, перемещение и
  изменение размера графиков за ручки, увеличение рамкой (щелчок — ×2, ⌥‑щелчок — ÷2),
  сдвиг «рукой», масштаб колесом с ⌘ и жестом щипка на трекпаде.
- Панель проекта: графики, наборы, объекты; видимость галочкой; контекстные меню.
- Групповая правка: выделите несколько наборов (⌘‑ или ⇧‑щелчок на графике или в панели
  проекта, ⌘A — все наборы графика) — цвет, толщина, символы, заливка и любые другие
  свойства в инспекторе меняются сразу у всех, одним действием отмены. Кнопка «Разные
  цвета по порядку» раскрашивает выделенные наборы различимыми цветами.
- Двойной щелчок по любому элементу (набору, оси, заголовку, легенде, надписи) открывает
  его свойства и ставит курсор в главное поле.
- Заливка под кривой: «Быстро → Заливка под кривой» или контекстное меню — до оси X
  (y = 0), до нижнего или верхнего края графика; цвет — светлый оттенок цвета линии.
- Порядок слоёв: наборы, графики и надписи двигаются вперёд/назад (⌘] ⌘[) и на
  передний/задний план (⇧⌘] ⇧⌘[) через «Правка → Порядок слоёв», контекстное меню или
  перетаскиванием в панели проекта (так же наборы переносятся в другой график). Как и в
  Grace, порядок задают номера наборов, поэтому файл остаётся совместимым с xmgrace.
- Интерфейс на русском и английском: «Вид → Язык / Language» (по умолчанию — язык
  системы). Словарь — `tools/i18n_en.json`; `tools/gen_i18n.py` проверяет, что все строки
  переведены.
- Инспектор свойств для страницы, графика, каждой оси, набора, легенды и объектов —
  все настройки Grace, сгруппированные по секциям.
- Таблица данных: правка ячеек, добавление/удаление строк, вставка из Excel/Numbers.
- Полная история отмен (⌘Z / ⇧⌘Z), перетаскивание — одна отмена.
- Шаблоны оформления (10): «Современный», «Для статьи», «Классический xmgrace»,
  «Журнальный» (как Nature/Science), «Для презентации» (крупный шрифт, толстые линии),
  «Тёмный», «Чёрно-белый» (для печати: стили линий и символы вместо цветов), «С сеткой»,
  «Минимализм», «Мягкий фон». «Галерея стилей…» (кнопка на панели, меню «График»,
  инспектор страницы) показывает ваш проект в каждом стиле — щёлкните, чтобы применить.
- Палитры: современная, классическая Grace, Okabe–Ito (для дальтоников), яркая (для
  тёмного фона), пастельная, насыщенная; раскраска выделенных наборов градиентом
  (viridis, тёплый, синий) — удобно для серии кривых.
- Расстановка графиков сеткой, подгонка полей под подписи.

**Анализ данных** (меню «Данные»)
- Набор из текста (⌥⌘N): каждая строка — точка, `20.0 -10.0` и `20.0 10.0` дают
  отрезок; пустая строка или `&` начинают новый набор; третий столбец — погрешность
  или ещё один Y. Строка `y = 0.5*x` или `y = sin(x)` добавляет функцию на видимом
  отрезке X (его и число точек можно задать). Числа, скопированные из Excel или
  текстового файла, вставляются на холст как новый набор (⌘V). У набора есть
  «Изменить данные как текст…» в контекстном меню.
- Формула из наборов (⇧⌘M, «Данные → Операции над наборами…»): новый набор по любому
  выражению из других наборов — `s1.y + s2.y + s3.y`, `s0 - s1 - s2`, `(s0 + s1) / 2`,
  `s0.y - 0.5*s1.y + x`, `g1.s0` (набор другого графика). `sN` без столбца — это `sN.y`,
  можно писать × ÷ −. Окно сразу подставляет сумму выделенных наборов, кнопки вставляют
  ссылки на наборы и операторы, «Сумма / Разность / Среднее выделенных» пишут формулу за
  вас. Если X наборов различаются, они пересчитываются на точки X первого набора формулы
  (или выбранного набора), точки вне общего диапазона пропускаются.
- Готовые операции (там же или в контекстном меню «Операции»): A + B, A − B, A × B,
  A ÷ B, A ^ B, где B — другой набор или число
  (к Y или к X, например перевод единиц); сумма и среднее ± σ нескольких выделенных
  наборов; −y, |y|, 1/y, нормировка на максимум или на площадь, вычесть минимум,
  поменять X и Y. Если точки X наборов не совпадают, второй набор линейно
  интерполируется на X первого; погрешности по Y распространяются. Результат —
  новый набор (подпись вроде «S0 + S1») или изменение исходных, в т.ч. всех выделенных
  сразу; окно заранее показывает, что получится.
- Формулы для наборов: `y = y*2; x = x/1000`, ссылки на другие наборы (`s1.y`),
  функции `sin exp ln log10 sqrt erf gamma j0 rnorm…`.
- Новый набор по формуле.
- Регрессия: линейная, полиномы до 10‑й степени, экспонента, степенная, логарифм
  (с R² и формулой).
- Нелинейная аппроксимация по своей формуле с параметрами `a0…a9` (Левенберг —
  Марквардт), шаблоны: Гаусс, Лоренц, экспонента, логистическая кривая…
- Скользящее среднее, производная, интеграл, спектр Фурье, гистограмма, интерполяция
  (линейная и сплайн), сортировка, статистика набора.

## Сборка на Mac (Apple Silicon)

Нужны Xcode Command Line Tools (`xcode-select --install`) и [Homebrew](https://brew.sh).

```bash
./packaging/build_macos.sh
```

Скрипт поставит Qt 6 и CMake через Homebrew, соберёт программу под arm64, прогонит
тесты и сделает `dist/NeoGrace.app` и `dist/NeoGrace.dmg`. Откройте dmg и перетащите
NeoGrace в «Программы». При первом запуске: правый щелчок по NeoGrace → «Открыть»
(программа подписана локально, без Developer ID).

После установки NeoGrace открывает `.agr` двойным щелчком в Finder.

**Без сборки у себя.** В репозитории есть сценарий GitHub Actions
(`.github/workflows/build-macos.yml`): выложите папку на GitHub — на каждом коммите
соберётся `NeoGrace.dmg` для Apple Silicon (вкладка Actions → Artifacts), а при метке
`v1.0.0` — ещё и релиз.

### Вручную

```bash
brew install qt cmake
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build -j
open build/NeoGrace.app
```

### Linux

```bash
sudo apt install qt6-base-dev qt6-svg-dev cmake g++    # Ubuntu 24.04
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
./build/NeoGrace
```

## Устройство

```
src/core   — без интерфейса: модель проекта, чтение/запись .agr, разметка текста,
             шкалы и деления, отрисовка QPainter, формулы, аппроксимация, экспорт
src/ui     — окно, холст, инспектор, таблица, диалоги, история отмен
tests      — автотесты ядра и интерфейса + 38 примеров из дистрибутива Grace
```

Свойства описаны схемами (`model.cpp`): одна запись задаёт ключевое слово `.agr`,
тип и значение по умолчанию — её используют и парсер, и запись файла, и инспектор.

Тесты: `cd build && QT_QPA_PLATFORM=offscreen ctest --output-on-failure`.

Совместимость с настоящим Grace проверяет `tests/grace_compat.sh build/NeoGrace`: каждый
пример пересохраняется через NeoGrace и рисуется `gracebat` 5.1.25. Сейчас 31 из 38
примеров совпадают попиксельно; в остальных — отличия в несколько пикселей (метка
времени, сглаживание старых заливок, двузначные годы в `times.agr`). Файлы старых
версий (Xmgr, ACE/gr, Grace 5.0) при открытии переводятся в современную семантику,
как это делает сам Grace, и сохраняются как версия 5.1.25.
`build/neograce_tests папка/` дополнительно сохраняет картинки всех примеров.

## Ограничения

- Графики Смита рисуются как обычные XY.
- Преобразования текста Grace (`\t{…}`, наклон `\l`) игнорируются; сам текст выводится.
- Регионы, «стек миров», связи графиков сохраняются в файле, но не редактируются.
- Шрифты Type 1 из Grace заменяются системными: Times → Times New Roman,
  Helvetica → Helvetica, Courier → Courier New, Symbol → греческие буквы Unicode.

## Лицензия

GNU GPL версии 2 или новее — как у Grace: NeoGrace использует узоры заливки Grace, а
примеры в `tests/data` взяты из дистрибутива Grace.
